## TROUBLESHOOTING

Q: "fatal: remote origin already exists"
A: Run: git remote remove origin
   Then run the add command again

Q: "Permission denied (publickey)"
A: Generate GitHub SSH key or use Personal Access Token
   Instructions: https://docs.github.com/en/authentication/connecting-to-github-with-ssh

Q: "Could not resolve host: github.com"
A: Check your internet connection
   Verify firewall settings allow git

Q: "fatal: Pathspec is in submodule"
A: Make sure you're in the correct directory:
   cd "c:\Users\Benny\System File\Desktop\it\dealership-review-app"
